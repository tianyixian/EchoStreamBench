# Dataset citations and media licensing

EchoStreamBench canonical657 is a composite evaluation suite built from item metadata and media references from existing public benchmarks. This repository distributes derived question metadata and aggregate results; it does not redistribute third-party videos. Users must follow the license, terms of use, and citation requirements of every source benchmark they access.

| `source_benchmark` | Citation / source note |
|---|---|
| `longvideobench` | Cite the original LongVideoBench release and follow its official data license. |
| `lvbench` | Cite the original LVBench/RIVER-derived source release and follow its official data license. |
| `mlvu` | J. Zhou et al., “MLVU: Benchmarking Multi-task Long Video Understanding,” arXiv:2406.04264. |
| `video_mme` | C. Fu et al., “Video-MME: The First-Ever Comprehensive Evaluation Benchmark of Multi-modal LLMs in Video Analysis,” arXiv:2405.21075. |
| `streamingbench` | J. Lin et al., “StreamingBench: Assessing the Gap for MLLMs to Achieve Streaming Video Understanding,” arXiv:2411.03628. |
| `ovo_backward` | J. Niu et al., “OVO-Bench: How Far is Your Video-LLMs from Real-World Online Video Understanding?”, CVPR 2025. |
| `rtv_bench` | Cite the original RTV-Bench release and follow its official data license. |
| `svbench` | Cite the original SVBench release and follow its official data license. |

Upstream papers, download locations, and license terms can change. Check each official source before redistribution or publication. The `source_media_sha256` and `question_sha256` fields identify the frozen source version; they do not grant rights to the underlying media or source dataset.
