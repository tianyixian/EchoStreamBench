# EchoStreamBench source-media license audit (2026-11-21)

This audit addresses one question: can the original video files from each source benchmark be copied into the EchoStreamBench Hugging Face dataset? A source is marked **no** unless an official source gives a clear redistribution grant covering the raw videos. A public download or an existing mirror is not, by itself, a redistribution license.

| Source benchmark | Official evidence | Raw-video redistribution decision | Reason |
|---|---|---|---|
| LongVideoBench | [HF dataset card](https://huggingface.co/datasets/longvideobench/LongVideoBench) | **No** | The card says the dataset contains web-video links, that LongVideoBench does not own the linked content, and that ownership/copyright remains with the source channels. Its CC-BY-NC-SA tag cannot grant rights to those videos. |
| LVBench | [Official README](https://github.com/zai-org/LVBench/blob/main/README.md), [HF dataset](https://huggingface.co/datasets/THUDM/LVBench) | **No** | The README states that the dataset is CC-BY-NC-SA-4.0, for academic research, and “We do not own the copyright of any raw video files.” It instructs users to download by YouTube ID. |
| MLVU | [Official README](https://github.com/JUNJIE99/MLVU/blob/main/README.md), [HF dataset](https://huggingface.co/datasets/MLVU/MLVU_Test) | **No** | The README states that it does not own the copyright of raw videos and provides video access to researchers subject to the license. This is access guidance, not a right to mirror the files. |
| Video-MME | [Official README, Dataset section](https://github.com/BradyFU/Video-MME#-dataset) | **No** | The official terms say the benchmark is for academic research, copyright belongs to video owners, and “Without prior approval, you cannot distribute, publish, copy, disseminate, or modify Video-MME in whole or in part.” |
| StreamingBench | [Official repository](https://github.com/THUNLP-MT/StreamingBench), [HF dataset](https://huggingface.co/datasets/mjuicem/StreamingBench), [issue #26](https://github.com/THUNLP-MT/StreamingBench/issues/26) | **No safe authorization** | The repository's MIT license covers code; no data license grants raw-video redistribution. Issue #26 says users should obtain raw videos independently; the maintainer only discusses redistribution of modified annotations. |
| OVO-Bench | [Official README, License](https://github.com/JoeLeelyf/OVO-Bench#license), [HF dataset](https://huggingface.co/datasets/JoeLeelyf/OVO-Bench) | **No** | The README requires CC-BY-NC-SA-4.0 and compliance with every source-dataset license. The HF card uses a conflicting CC-BY-SA-4.0 tag and gives no separate raw-video grant. |
| RTV-Bench | [Official repository](https://github.com/LJungang/RTV-Bench), [HF dataset](https://huggingface.co/datasets/RTVBench/RTV-Bench), [paper](https://arxiv.org/abs/2505.02064) | **No safe authorization** | The HF card has a `license: mit` metadata tag, but the repository has no LICENSE file or raw-video terms. The paper says the benchmark contains 552 videos “sourced from the internet.” The MIT tag therefore does not establish that the authors own and can relicense every video. |
| SVBench | [Official README](https://github.com/sotayang/SVBench), [HF dataset card](https://huggingface.co/datasets/yzy666/SVBench) | **No** | The card's Apache-2.0 tag is followed by: “Videos and annotations are for research purposes only. Users must comply with the original licenses of datasets.” The listed sources include YT-Temporal-1B, YouCook2, MovieChat, Panda-70M, Ego4D, and ActivityNet. |

## Result

No source currently has an unambiguous official grant that allows us to redistribute its original videos in a new public HF repository. Therefore no raw-video upload was made. The existing EchoStreamBench release should continue to distribute question metadata, source benchmark names, video IDs, official acquisition links, and the evaluation protocol. A self-contained media mirror would require written permission from the relevant benchmark authors and, where applicable, the original video owners/platforms.

The public release is answer-released for reproducibility and remains media-free. This audit does not change the paper or its abstract.
